# CLAUDE.md

Context for Claude Code sessions on this repo. Read this before changing anything.

## The project

Website rebuild for **Prairie Clean Enterprises (PCE)**, a Weyburn, Saskatchewan company that buys flax straw from
farmers and processes it into flax fibre, fuel pellets, cat litter (Prairie Clean Litter) and animal bedding
(Prairie Clean Flax Bedding). Built by **Mighty Design** (Trent). It replaces a WordPress + Elementor site.

PCE is the client. Brand, copy, numbers and investor terms come from PCE; never invent facts, figures or quotes.
Unknown values stay as visible placeholders like `[ASH %]`.

## Audiences (the navigation is built around them)

Fibre and fuel buyers (B2B) · consumers and retailers (litter, bedding) · flax farmers selling straw ·
accredited investors · job seekers · press.

## Stack and why

- **Next.js 15.4.11** — Payload 3.92 peer range is `>=15.4.11 <15.5` or `>=16.3.3`. Do not bump to 15.5.
- **Payload CMS 3** inside the Next app (`src/app/(payload)`), Postgres adapter, admin at `/admin`.
  Chosen over Sanity so content and form submissions live in one database and one admin.
- **Tailwind CSS 4**, CSS-first: tokens in `src/app/(frontend)/globals.css` (`@theme`). There is no `tailwind.config.ts`.
- **Postgres**: Neon in production (Vercel integration sets `DATABASE_URL`). Local dev uses any Postgres.
- **Vercel**: Hobby during development, PCE-owned **Pro** team before launch (Hobby is non-commercial only).
- **Uploads**: Vercel Blob when `BLOB_READ_WRITE_TOKEN` is set, local disk otherwise.

## Layout

- `src/app/(frontend)` — public site. `[[...slug]]` renders CMS pages (home is slug `home`);
  `products`, `news`, `careers` are collection templates. `actions.ts` holds the form server actions.
- `src/app/(payload)` — generated by Payload. Don't edit by hand; regenerate with `pnpm generate:importmap`.
- `src/collections` — Pages, Products, News, Team, Partners, Jobs, Media, Resumes, Users and four inbox
  collections (contact, straw offers, investor requests, job applications).
- `src/blocks/config.ts` + `src/components/blocks/RenderBlocks.tsx` — page builder blocks (schema + rendering).
- `src/seed` — content from the old site; `pnpm seed`.
- `src/migrations` — committed schema migrations. `push` is off: every schema change needs a migration.
- `docs/reference-schema.sql` — the original hand-written schema the collections were modelled on. Reference only.

## Rules that matter

- **Schema changes**: edit the collection, then `pnpm migrate:create <name>`, `pnpm migrate`, `pnpm generate:types`.
  Commit the migration and the types together.
- **Public reads use the local API**, which skips access control. Always filter `_status: published` (see
  `src/lib/payload.ts`). Inbox collections are never readable publicly; submissions are created only via server
  actions with `overrideAccess`.
- **Forms**: validate on the server, honeypot field `company_website`, max 5 submissions per hashed IP per hour.
  Raw IPs are never stored. Resume uploads are capped at 4 MB (Vercel's request limit is 4.5 MB).
- **Content edits revalidate the whole site** through `src/hooks/revalidate.ts`. Seed and scripts pass
  `context.disableRevalidate`.
- **Accessibility is a requirement (WCAG 2.2 AA)**: one `h1` per page, real buttons and links, labels on every input,
  visible focus, 44px targets, no `maximum-scale` on the viewport. Check contrast for any new colour pairing.

## Design tokens

The palette comes from the current prairiecleanenterprises.com (Elementor kit and page styles) and the logo. PCE chose
those colours deliberately, so keep them:

| Role | Colour |
|---|---|
| Olive (buttons, primary fills) | `#96A924`, hovers `#819217` / `#748410` |
| Teal (links, icons) | `#007B9A` |
| Sky (headings and accents on dark bands) | `#6EC1E4` |
| Green (bands, accent) | `#54864D` |
| Charcoal (text, dark bands, footer) | `#262B2B` |
| Light grey (bands) | `#F3F3F3` |
| Grey (secondary text) | `#606060` |
| Straw, Maple Red (from the logo) | `#9D7C55`, `#BE1522` |

Components use semantic tokens (`bg-primary`, `text-on-primary`, `bg-inverse`, `text-on-inverse`,
`text-on-inverse-accent`, `text-link`, `bg-selected`), never raw hex or scale steps like `bg-teal-900`.

Contrast decisions (all checked to WCAG 2.2 AA; where an original pairing fails, the colour stays and the pairing changes):
- Olive with white text is 2.6:1, so olive buttons carry **charcoal** text (5.5:1).
- Teal is 4.9:1 on white but 4.4:1 on the light grey band, so small links on grey use `#006A86` (the tinted-surface override).
- Sky `#6EC1E4` is only for dark bands (7.1:1 on charcoal); it fails on white (2.0:1).
- Green `#54864D` is 4.3:1 on white, so text uses `#45703E` (5.8:1); the original is for fills and large type.
- Straw is for graphics and large type only.

Type: Inter (variable, headings and body) via `next/font`. PCE fixed the logo and colours only;
fonts can change.

SVG safety: logos in `public/brand/` load through `<img>` (never inline, never `dangerouslySetInnerHTML`), are served with a locked-down CSP, and `pnpm check:svg` fails on scripts, event handlers, external references or any tag outside an allow list. Run it whenever an SVG is added; `pnpm ci` runs it.

Block thumbnails shown in the Payload layout picker live in `public/block-previews/` (one SVG per block, set with
`imageURL` in `src/blocks/config.ts`). Add one when you add a block.

## Commands

```bash
pnpm dev | pnpm build | pnpm start
pnpm typecheck
pnpm migrate | pnpm migrate:create <name>
pnpm generate:types | pnpm generate:importmap
pnpm seed                      # SEED_RESET=1 to replace seeded content
```

Building without network access to Google Fonts fails at `next/font`; on Vercel it works normally.
